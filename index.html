✂ Cắt ảnh phiếu

Điều chỉnh bốn mép ảnh để loại bỏ phần thừa. Ảnh sau khi cắt sẽ được dùng để quét OCR.

⚙️ Cài đặt quét phiếu

Lấy API key tại Google AI Studio ↗. Key được lưu cục bộ trên thiết bị.

Chưa tải file

Mỗi dòng trong file là một API key. Dòng trống và dòng bắt đầu bằng # sẽ được bỏ qua. Khi API đạt 20 lượt gọi cục bộ hoặc nhận lỗi 429, ứng dụng sẽ tự chuyển sang API còn lượt.

Bộ đếm này theo dõi các lượt gọi do ứng dụng thực hiện trên thiết bị này; đây không phải quota thực tế từ Google.

Tự động dùng Mobile/Desktop theo kích thước màn hình, hoặc khóa một chế độ cố định.

Số phiếu luôn được trích xuất. Chọn các cột trong bảng mẫu DynaPac bên dưới.

Ghi hướng dẫn riêng cho từng trường để Gemini đọc đúng các mẫu phiếu khác nhau. Các hướng dẫn chỉ áp dụng khi quét bằng Gemini AI.
